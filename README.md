# 前端风格 · 白底双色配色方案

## 一、格式声明

本目录以「一个风格 = 一组同名文件」的方式组织，便于独立查看、复用和继续扩展。

### 1. 文件组织

```text

├─ 启动预览.bat           # Windows 下双击启动本地预览服务
├─ server.js              # 零依赖本地静态服务 + 目录扫描接口
├─ README.md              # 本说明
├─ 清新绿黄.html          # 独立可运行的完整页面
```

### 2. HTML 文件格式

每个 `<风格名>.html` 都是**完整、独立、无外部依赖**的单文件页面：

- 仅使用原生 HTML + CSS，不引用 CDN、字体、图片或 JS 框架；
- 可直接双击打开，也可以单独部署；
- 主题色以 CSS 自定义属性写在 `:root` 中，修改颜色只需替换变量；
- 页面 `<head>` 中包含可供程序读取的元信息：

```html
<meta name="theme-name" content="清新绿黄">
<meta name="theme-description" content="白色为底 · 绿色主色 · 黄色点缀">
<meta name="theme-primary" content="#15803d">
<meta name="theme-accent" content="#f5c518">
```

### 3. TXT 文件格式

每个 `<风格名>.txt` 与同名 HTML **一一对应**，并严格遵循以下规则：

- **只包含代码**，即该风格 HTML 的完整源代码；
- 不包含 Markdown 代码围栏（例如用三个反引号包裹 html 的写法）、标题、说明、署名或授权注释；
- 与同名 `.html` 的内容逐字一致，可直接全选复制后另存为 `.html` 使用；
- 统一使用 UTF-8 编码、LF 换行。

### 4. 命名规则

- 文件名即风格名，HTML 与 TXT 必须同名；
- 中文名称直接作为文件名，不使用拼音或编号前缀；
- 新增风格时保持「一 HTML + 一 TXT」成对出现，预览会自动按文件名与元信息展示。

## 二、预览方式

### 方式 A：本地服务（推荐，支持自动发现新增 HTML）

双击 **`启动预览.bat`**，或在当前目录执行：

```bash
node server.js
```

然后打开 <http://127.0.0.1:8000/>。

该方式下，`预览.html` 通过 `/api/themes` 实时读取目录，**新增任意 `.html` 后刷新页面即可自动出现**，不需要修改预览文件。`server.js` 仅使用 Node.js 内置模块，无需安装依赖。

如果 8000 端口被占用，可在命令行临时指定端口：

```bat
set PORT=8080 && node server.js
```

### 方式 B：直接双击 `预览.html`

浏览器在 `file://` 协议下禁止网页自行读取目录，因此会展示内置的 8 套清单。此时可以：

1. 点击工具栏中的「选择文件夹」，授权读取当前目录后扫描全部 HTML（Chrome / Edge 支持）；
2. 或改用方式 A，让新增文件完全自动收录。

### 方式 C：任意静态服务器

```bash
python -m http.server 8000
```

打开 <http://127.0.0.1:8000/预览.html>。预览会先尝试 `/api/themes`，不可用时自动解析目录列表，同样可以发现新增 HTML。

---

## 三、预览读取逻辑

`预览.html` 按以下优先级发现模块：

1. **本地服务接口**：请求 `./api/themes`，由 `server.js` 扫描目录并读取各 HTML 的 `<meta name="theme-*">` 信息；
2. **目录列表解析**：无法使用接口时，请求 `./` 并解析静态服务器返回的目录超链接；
3. **本地文件兜底**：`file://` 环境下展示内置清单，并支持 File System Access API 手动选择文件夹；
4. **筛选与展示**：结果按已知风格顺序排序，其余模块按名称排序；每个模块通过 `<iframe>` 独立渲染，互不干扰。

因此，**通过本地服务打开时，新增 HTML 不需要改 `预览.html`**。

---

## 四、新增一套风格

1. 复制任意现有 `.html` 文件，重命名为新风格名，例如 `海盐青提.html`；
2. 修改 `<title>`、四个 `theme-*` 元信息，以及 `:root` 中的配色变量；
3. 将修改后的 HTML 源码原样保存为同名 `.txt`，例如 `海盐青提.txt`，确保 TXT 中没有任何额外说明文字；
4. 刷新预览页；使用本地服务时会自动出现，无需改动预览代码。
